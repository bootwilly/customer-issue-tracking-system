# 主機 pdo_mysql 換成 nd_pdo_mysql，移除程式端補救  (2026-11-24)

症狀：客戶新單存檔後顯示「找不到這張客戶單」；截圖貼上失敗。
根因：主機的 pdo_mysql.so 連結 libmariadb 10.5.5，與 PHP 8.5 ABI 不相容：
- native prepares 讀回錯位資料（前一次 admin 登入失敗）
- emulated prepares 每欄都變成字串 → `$t->project_id !== $projectId` 永遠成立
- getColumnMeta 也壞掉（每欄都回報 DECIMAL），無法從 metadata 推回型別

處理：
- 使用者在 cPanel Select PHP Version > Extensions：取消 pdo_mysql，改勾 nd_pdo_mysql。
- 探測確認：client=mysqlnd 8.5.6；native 與 emulated 都正確，整數為 int；CLI /usr/local/bin/php 8.5.6 + mysqlnd。
- 移除補救：
  - cits/config/database.php：刪除 PDO::ATTR_EMULATE_PREPARES 那行（恢復 Laravel 預設）。
  - cits/app/Providers/AppServiceProvider.php：刪除 TypedMariaDbConnection 的 resolverFor 註冊。
  - cits/tests/Feature/TypedConnectionTest.php：刪除註冊測試。
- 未刪檔（需使用者同意）：cits/app/Database/TypedMariaDbConnection.php、cits/tests/Feature/TypedConnectionTest.php（目前未被使用）。
- 測試 74/74，已上傳 webdav-app。

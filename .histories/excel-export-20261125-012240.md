# 四個列表的 Excel 匯出（依目前篩選條件）  (2026-11-25)

使用者決定：xlsx（openspout）；要看詳細內容 → 清單標題連到「詳細」分頁的區塊；客戶（含 client_view）可匯出；上限做成可調設定。

主控（我）— 共用核心：
- composer require openspout/openspout（^5.15）：cits/composer.json、composer.lock。
- app/Services/Export/{ExportBook,ExportSheet,DetailBlock,ExportLink,HtmlToText,ExportColumnService,XlsxExportService,ExportSettingService}.php
  清單頁（凍結標題、自動篩選）、詳細頁（每筆一個區塊，與清單雙向超連結）、匯出資訊頁；公式注入防護；單格 32000 字截斷；
  日期：00:00 視為純日期，其他轉台北時間；超過上限直接報錯（不靜默截斷）；每次匯出寫 events（subject_type export）。
- workflow.php：所有角色加 data.export；export_client_tickets / export_pm_tickets / export_pm_issues / export_dev_issues（含 week）/ export_test_issues 欄位 lookup；export.max_rows=5000。
- 匯出設定頁：app/Http/Controllers/Admin/ExportSettingController.php、resources/views/admin/settings/export.blade.php、routes/modules/export.php、layout 導覽「匯出設定」。
- PM 合併匯出：app/Http/Controllers/Pm/PmController.php（export、filters()、canExport）、routes/modules/pm.php（pm.export）、resources/views/pm/index.blade.php（按鈕）。
- deploy/make_upgrade_sql.php：加入 permissions 與 role_has_permissions 的 INSERT IGNORE。
- tests/Feature/ExportCoreTest.php；IssueExportTest.php 追加 PM 合併匯出測試。

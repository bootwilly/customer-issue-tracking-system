# 個人工作台

2026-11-28 20:11（台北）

## 使用方式

登入並選定專案後進入「我的工作台」。從單據連結登入仍可回原頁。以同一個帳號兼任開發與測試時，清單同時涵蓋兩個角色，派工移交後會跟著原單的階段更新。

| 分頁 | 取數條件 |
|---|---|
| 我的待辦 | 本人名下的未完成會議事項、目前階段的 DEV 或 Test 指派、個人結案收尾、已接收且需處置的客戶單，或本人開立且待補充或結案的客戶單。 |
| 團隊待處理 | 可接收且沒有有效編輯鎖的客戶單、待審展延、待上線，以及由上線群組完成的收尾。 |
| 我的排程 | 目前指派中已填寫的事項期限、開發完工日、測試或上線日期。未結束且日期已過的工作仍能追查。 |
| 我的追蹤 | 依個人關注紀錄查詢內部單及客戶單，以原單異動與事件的較新時間排序。 |

收尾以內部單為一筆，點連結後在原頁逐項填寫。會議事項和展延審核直接連到該筆資料。常用查詢沿用原清單儲存的條件、名稱及專案權限。

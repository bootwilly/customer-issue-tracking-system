# 開發管理結案收尾清單與 PM 派工時間

2026-11-28 18:11（台北）

- 開發管理新增「結案收尾」分頁。每張內部單的每個收尾輪次各列一筆，依送出時間由早至晚排列，每頁 20 筆。預設顯示專案內收尾中的輪次，支援查詢已完成、已撤回、全部、單號、標題與「只看我待確認」。
- 結案方式與送出時間取自該輪的事件。進度統計包含該輪所有任務，個人篩選比對尚可確認的角色與上線權限。單號連回內部單收尾區。
- 四個分頁及其 Excel 共用 PM 派工時間。系統從專案內部單的狀態事件，找出第一次以派工轉換進入「待開發」的時間，轉為台北時間。無事件顯示「—」。既有資料無須回填。
- 收尾分頁和 Excel 共用查詢、排序與欄位。Excel 包含所有符合條件的輪次，沿用既有的匯出權限與筆數上限。

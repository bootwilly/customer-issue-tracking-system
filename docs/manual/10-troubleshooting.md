# 10. 常見問題與錯誤排除

## 10.1 登入與帳號

| 訊息／現象 | 原因 | 處理 |
|---|---|---|
| 帳號或密碼錯誤 | 輸入錯誤 | 檢查大小寫；用「忘記密碼」或請管理員重設 |
| 登入嘗試次數過多 | 連續錯誤達上限 | 等畫面顯示的分鐘數 |
| 此帳號已停用 | 帳號被停用 | 找系統管理員 |
| 目前沒有可使用的專案 | 未加入任何啟用中的專案 | 請管理員加入專案並指派角色 |
| 您無權使用此專案 | 不是該專案成員 | 同上 |
| 要求次數過多 | 忘記密碼送太多次 | 稍後再試 |
| 重設連結無效或已過期 | 超過 60 分鐘或已使用 | 重新申請 |
| 收不到信 | 郵件未啟用、個人關閉 Email 通知、垃圾信匣 | 依序檢查 |
| 送出表單出現 419 | 頁面停留太久，登入階段過期 | 重新整理並登入；編輯器草稿可還原 |

## 10.2 客戶單

| 訊息／現象 | 原因 | 處理 |
|---|---|---|
| 問題已拋單給 DEV/Test，內容已鎖定 | 已拋單 | 用留言補充 |
| 問題已拋單處理中，不能取消 | 同上 | 在留言請 PM 處理 |
| ○○ 正在編輯這張單 | 他人持有編輯鎖 | 請對方儲存或取消；異常關閉時等 5 分鐘 |
| 編輯鎖已失效 | 閒置、斷線或電腦休眠 | 取消後重新編輯，還原草稿 |
| 這張單已被其他人修改 | 版本衝突 | 重新整理後再改 |
| 請選擇異常類別 | 異常回報未選類別 | 補選 |
| 內容不可空白 | 只有空行 | 輸入內容 |
| 沒有「開立新單」按鈕 | 客戶 View 或內部帳號 | 需客戶 PM 角色 |
| 沒有「結案」按鈕 | 狀態不是「待結案」 | 等內部完成上線 |

## 10.3 內部單

| 訊息／現象 | 原因 | 處理 |
|---|---|---|
| 客戶 ○○ 正在編輯中／暫時不能接收 | 客戶持有編輯鎖 | 稍後重整 |
| 客戶正在編輯客戶單 ○○，請等客戶儲存或鎖定逾時後再派工 | 派工時客戶持有編輯鎖 | 稍後再派工 |
| 指派的人員沒有這個專案的對應權限 | 選的人沒有 DEV／Test 角色 | 請專案管理員指派角色 |
| ○○ 尚未接收或已結束，不能建立內部單 | 客戶單狀態不符 | 先接收 |
| 目前沒有可執行的狀態變更 | 角色或狀態不符 | 對照 [2.5](02-workflow.md) |
| 此狀態變更必須填寫：欄位代碼 | 必填未填 | `assignee_dev_id`＝DEV 負責人、`assignee_test_id`＝Test 負責人、`planned_due`＝預計完工日、`package_id`＝更新包、`test_scheduled_at`＝排程測試日、`release_planned_at`＝預計更新日、`cancel_reason`＝原因 |
| 請填寫給客戶看的說明 | 取消有連結客戶單的內部單 | 補填 |
| 已拋單，主體內容已鎖定 | 派工後不可改本文 | 用「補充說明」 |
| 預計完工日已設定 | 只能設定一次 | 申請延期 |
| 開發清單找不到單 | 「我負責的」勾著，且單的 DEV 負責人不是你 | 取消勾選 |
| 測試清單「我負責的」是空的 | 送測時指定的是別人，或是舊單沒有 Test 負責人 | 取消勾選，看「待測試」 |
| 客戶單沒有自動轉待結案 | 還有未排除且未上線的內部單 | 到客戶單看「相關內部單」 |

## 10.4 上傳與編輯器

| 訊息／現象 | 處理 |
|---|---|
| 不允許的檔案類型 | 壓成 `.zip` 或改用允許的格式 |
| 檔案超過大小上限 | 壓縮、分割或裁短影片（上限 100 MB） |
| 分段尚未上傳完整／檔案大小不符 | 網路中斷，重新上傳 |
| 只接受圖片檔 | 非圖片請用「附加檔案」 |
| 游標要先放在表格裡 | 點進表格再操作；合併需選多格 |
| 沒有「繪圖」按鈕 | 手機版不提供 |

## 10.7 流程圖

| 訊息／現象 | 處理 |
|---|---|
| 草稿已被其他人更新 | 重新開啟編輯器後再修改（本機仍保留你的編輯內容） |
| 流程圖已「失效」 | 先「設為生效」 |
| 一份流程圖只能有一頁 | 拆成多份 |
| 內容中沒有 mermaid 區塊 | 加上 ` ```mermaid ` 區塊 |
| 流程圖過大 | 移除貼入的大圖 |
| 發布按鈕沒出現 | 需先開啟「草稿」檢視，且有發布權限 |
| 其他成員看不到 | 尚未發布 |

## 10.8 會議

| 訊息／現象 | 原因 | 處理 |
|---|---|---|
| 沒有「＋ 新增會議」按鈕 | 客戶 View 或只有專案管理員角色 | 需客戶 PM、內部 PM、DEV 或 Test |
| 沒有權限編輯這場會議 | 非發起人／與會者；或客戶要改內部發起的會議 | 請發起人或內部 PM 處理 |
| 會議已「取消」，不能編輯 | 取消的會議唯讀 | 發起人或內部 PM「改為已排定」 |
| 會議紀錄已被其他人更新 | 版本衝突 | 重新整理、還原草稿後再存 |
| 討論事項一直顯示「尚未儲存」 | 新的一列還沒填問題點 | 先填問題點 |
| 頁面已過期，請重新整理 | 登入階段過期 | 重新整理（先複製尚未存入的文字） |
| 負責人必須是專案成員 | 該帳號已移出專案或停用 | 改選其他人 |
| 客戶看不到討論內容 | 還沒完成紀錄 | 完成紀錄後自動顯示 |
| 「我的待辦」是空的 | 只列指定給你且追蹤中的事項 | 確認負責人與事項狀態 |
| 找不到符合條件的會議 | 篩選條件仍在（切換分頁會保留） | 按「清除條件」 |
| 沒有「匯出 Excel」按鈕 | 在「我的待辦」分頁，或只有專案管理員角色 | 切到其他分頁；需匯出權限 |
<!-- internal -->
| 客戶看不到整場會議 | 未開放給客戶 | 按「開放給客戶」 |
| 找不到問題單「單號」 | 單號錯誤或屬於其他專案 | 確認單號與目前專案 |
| 這張單已在該會議的討論事項中 | 重複加入 | 不需處理 |
<!-- /internal -->

## 10.9 補充資料、關注、查詢

| 訊息／現象 | 原因 | 處理 |
|---|---|---|
| 沒有「在下方留言回覆」 | 客戶 View 或單據已不能留言 | 請客戶 PM 回覆 |
| 每個清單最多 20 個查詢 | 達到上限 | 刪除不用的查詢 |
| 已經有同名的查詢 | 改名撞名 | 換一個名稱 |
| 沒有出現重複問題提示 | 標題少於 2 個字，或用字差異太大 | 用清單關鍵字搜尋 |
| 取消關注後仍收到通知 | 你是該事件原本的通知對象 | 正常行為 |
<!-- internal -->
| 這張單已經在等待客戶補充 | 已有等待中的要求 | 先「取消要求」再重發 |
| 目前不能要求客戶補充資料 | 單據已結束或沒有權限 | 需內部 PM，且單據未結束 |
| 客戶回了但仍顯示「等待客戶補充」 | 回覆的不是客戶帳號 | 請客戶帳號回覆，或取消要求 |

## 10.10 相依、標籤、更新包

| 訊息／現象 | 原因 | 處理 |
|---|---|---|
| 需等待 ○○ 上線或排除後才能派給 DEV | 上游單未完成 | 等上游完成，或由 PM 移除相依 |
| 找不到內部單「○○」 | 單號錯誤或屬於其他專案 | 確認單號 |
| 不能相依自己／這兩張單已經有相依關係 | 重複或錯誤的設定 | 不需處理 |
| ○○ 已經（間接）在等待 ○○，不能形成循環 | 會造成互相等待 | 重新檢視相依方向 |
| Test 新發現的單直接進 DEV，不能設定為需等待其他單 | 規則限制 | 改用「相關」 |
| 標籤不存在或已停用 | 頁面開著時標籤被停用 | 重新整理 |
| 沒有可勾的標籤 | 尚未建立 | 系統管理員到「選項管理 → 內部單標籤」新增 |
| 請勾選要套入的問題單 | 沒有勾選 | 先勾選 |
| ○○ 目前的狀態不能套入更新包 | 單已不是「開發中」 | 重新整理 |
| ○○ 還沒有 Test 負責人，請指定測試人員 | 沿用原 Test 但有單沒有 | 在對話框選 Test |
| ○○ 已開始測試或已上線，不能移出更新包 | 只有「開發中」「待測試」能移出 | 請測試人員判定「仍有異常」退回；已上線無法變更 |
| 沒有「套入問題單…」 | 沒有開發中的單，或沒有 DEV 權限 | |
